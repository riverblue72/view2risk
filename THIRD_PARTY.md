# Third-party sources

The official reference files in `src/closure/docs/official_*.py` come from AIR-THU/DAIR-V2X. Their source URLs and content hashes are recorded in `official_sources.json`. Original notices are retained; the upstream Apache 2.0 text is provided in `third_party/DAIR-V2X-LICENSE`.

Datasets remain subject to their providers' terms. No raw archives, camera frames, point clouds, full trajectories, videos, or model checkpoints are included. A code repository license does not establish the redistribution terms of a dataset.

- SPD/TFD: https://github.com/AIR-THU/DAIR-V2X-Seq
- IMPTC: https://github.com/kav-institute/imptc-dataset
- IMPTC files/checksums: https://zenodo.org/records/14811016

Aggregate research tables and plots are provided with the original analyses' limitations. This repository does not assign a new blanket license to upstream code or datasets.
