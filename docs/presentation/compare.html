공개된 세 이벤트의 여러 예측 시점입니다. 시점 수와 보행자 수는 다릅니다. 기본 모드는 경로·시간·관측오차 결과와 해당 시점의 정답이 모두 있는 사례만 사용합니다.

표시용 종방향 속도: 1.2 m/s 미만 / 1.2~1.5 m/s 미만 / 1.5 m/s 이상. 가속도: −0.3 m/s² 미만 / ±0.3 이내 / +0.3 초과. 중간 범위는 뚜렷한 가감속 판정을 보류합니다. 실제 센서 noise floor는 측정되지 않았습니다. 이 고정 UI 기준은 연구 결과의 기존 subgroup 정의나 모델 입력을 바꾸지 않습니다.

DD-MDN 지표와 입력 설명

세 장은 같은 카메라·보행자·기록시각입니다. 장면을 드래그하면 함께 회전하고 스크롤하면 확대합니다. 예측 기준 시점은 고정이며, 재생은 저장된 분포의 미래 시간을 따라갑니다. 새 관측으로 예측을 갱신하는 Rolling Forecast는 위의 전체 기록 화면에서 확인할 수 있습니다. 지도 속 파랑·초록 십자선은 원본 지도에 포함된 고정 표시이며 모델 예측이 아닙니다.

색으로 표시된 HDR 영역은 무엇인가요?

미래 특정 시점에 보행자가 있을 것으로 예측한 공간입니다. HDR68과 HDR95는 서로 다른 확률 질량의 영역입니다. 안전거리나 충돌위험 영역이 아닙니다. 표시된 대표 경로 가설의 confidence를 정규화된 발생확률로 해석하지 않습니다.

XGBoost — 언제 횡단을 완료할까요?

가로축은 앞으로의 시간, 세로축은 그 안에 완료할 확률입니다. 같은 눈금에서 DD-MDN과 비교합니다.

XGBoost AFT 횡단 완료까지 남은 시간의 분포

가로축: 예측 후 시간(s) · 세로축: 그때까지 완료할 확률. 예측 경로를 생성하지 않습니다.

같은 실제 기록 · 예측 경로 아님
Expert · 상세 CDF와 비교 수치

확률은 모델 정확도가 아닙니다. 분홍선은 이 보행자의 관측된 Exit 시각입니다. 아래 표의 (p−y)²는 개별 Brier 기여이며 전체 Brier Score가 아닙니다.

어떤 이동 정보를 사용하면 완료시간 예측이 달라질까요?

같은 시점에 대한 별도로 학습한 세 모델의 저장 결과입니다. 개별 특징의 인과효과를 측정하는 조작이 아닙니다.

M2는 주변 사람과 장소를 함께 추가합니다. M2−M1을 혼잡만의 효과로 해석할 수 없습니다. 가속도나 혼잡의 독립적인 성능 이득은 확립되지 않았습니다.

AFT 수식과 검열된 학습 정답
$$\log T=f_{\mathrm{XGB}}(z)+\sigma Z$$

T는 남은 완료시간(s), z는 현재까지의 특징, f는 학습한 함수입니다. 끝까지 관측하지 못한 경우에는 유효 관측의 시간 하한을 사용했습니다. XGBoost는 2D 미래 경로를 생성하지 않습니다. Calibration은 별도 분할에서 적합한 저장 결과입니다.

관측오차 실험 · 같은 사람과 같은 시점

관측오차 R — 위치가 부정확하면 예측이 어떻게 바뀔까요?

SPD 주석 차이에서 추정한 오차를 합성했습니다. 실제 IMPTC 카메라 오차를 측정하거나 보정한 결과는 아닙니다.

Observation R 오차를 더한 DD-MDN

SPD 주석 차이를 이용한 합성 관측오차 실험입니다. 실제 IMPTC 센서 보정이 아닙니다.

모든 오차 조건을 포함한 동일 좌표축·축척을 사용합니다. 체크박스는 표시만 바꾸며 예측을 다시 계산하지 않습니다. 선: 대표 미래 경로 · 점선 경계: 선택 시점의 HDR95 · 분홍: 실제 미래.

같은 실제 Exit 시각 · 저장된 H1~H4 점만 표시합니다. 중간 확률을 보간하거나 새 추론을 실행하지 않습니다.

한 사례의 포함 여부와 전체 Coverage는 다릅니다
관측모형 · Kalman · FFBS
$$y_t=Hx_t+b_R+\epsilon_t,\quad\epsilon_t\sim\mathcal N(0,R)$$

관측 위치 y(m), 잠재 상태 x, 위치 선택 H, Train 편향 b(m), 공분산 R(m²). Kalman Filter는 상태를 추정하고 FFBS는 시간 상관을 유지한 가능한 과거를 뽑습니다. 이 과거를 기존 DD-MDN에 넣은 Monte Carlo 결과가 R+Q입니다. 오차 배율 λ의 covariance는 λ²R이며 Clean에는 편향도 추가하지 않습니다.
