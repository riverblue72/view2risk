MATH & IMPLEMENTATION

Mathematical Methodology

수식의 단위·평가 범위와 실제 코드의 계산을 함께 설명합니다.

A · Behavioral Q

\[p_Q(\mathbf{x}_k\mid X_{past},C)=\sum_{m=1}^{M}\pi_{km}\mathcal{N}(\mathbf{x}_k;\mu_{km},\Sigma_{km}),\quad\sum_m\pi_{km}=1\]
\[X_{1:8}^{(j)}\sim\sum_a w_a\mathcal{N}_{16}(\mu_a,\Sigma_a),\quad\sum_a w_a=1\]

시점별 GMM과 joint trajectory mixture는 DD-MDN의 서로 다른 두 head입니다. Q-only는 추가 R 적분 없이 주어진 과거 관측에 조건화한 예측입니다. 20개 discrete hypothesis의 confidence는 정규화된 발생확률이 아닙니다.

B · Observation R

\[\mathbf{y}_t=H\mathbf{x}_t+\mathbf{b}_R+\epsilon_t,\qquad\epsilon_t\sim\mathcal{N}(0,R)\]

위치 m, bias m, covariance m². SPD 카메라–LiDAR 주석 차이의 Train 적합값입니다. 실제 detector error가 아니며 시각 차이도 포함할 수 있습니다. FilterPy 상태는 [x,y,vx,vy], q_filter=0.5m²/s³로 DD-MDN의 행동 Q와 다릅니다.

FilterPy · V2X-Seq

C · 선택적 Legacy R+Q

\[p(X_{future}\mid Y_{past},C)=\int p_Q(X_{future}\mid X_{past},C)\,p_R(X_{past}\mid Y_{past})\,dX_{past}\]
\[\widehat p(X_{future}\mid Y_{past},C)=\frac1S\sum_{s=1}^{S}p_Q(X_{future}\mid X_{past}^{(s)},C),\quad S=8\]

현재 origin까지 관측한 이력에서 FFBS로 시간 상관을 유지한 과거 경로를 샘플링합니다. 각 샘플에 맞춰 좌표·Heading·지도 crop을 갱신하고 실제 DD-MDN 분포를 동일 가중치로 혼합합니다. 원본 센서와 데이터셋의 축·분포 전이는 가정이며 DD-MDN 내부 잡음과 중복될 수 있습니다. 위치 차분의 잡음 증폭과 학습 입력 분포 불일치가 남아 있습니다.

D · Crossing과 Rolling Forecast

\[T_{exit}=\inf\{\tau>0:\text{opposite semantic Exit crossed at }\tau\}\]
\[\widehat P(T_{exit}\le H)=\frac1J\sum_{j=1}^{J}\mathbf1[T_{exit}^{(j)}\le H],\quad H\in\{1,2,3,4\}\,s\]

현재 위치가 Exit 이전인 origin만 대상으로 joint samples의 최초 경계 통과를 계산합니다. 0.5초 표본 사이를 선형 보간하며 GT의 0.12초 연속 확인 조건과 다릅니다. IMPTC는 Simulation-only, inD는 Exit 미확정으로 확률을 표시하지 않습니다.

매초 새 실제 관측으로 다시 조건화하는 Rolling Forecast는 최초 시점에서 15~20초 전체 완료시간을 예측하는 것이 아닙니다. 캐시된 origin 이후에는 새 예측을 만들지 않고 GT 재생만 표시합니다.

E · 오차와 확률분포 평가

\[\mathrm{ADE}=\frac18\sum_{k=1}^{8}\|\widehat{\mathbf{x}}_k-\mathbf{x}_k^{GT}\|_2,\quad\mathrm{FDE}=\|\widehat{\mathbf{x}}_8-\mathbf{x}_8^{GT}\|_2\]
\[\mathrm{NLL}=-\frac1{8N}\sum_{n=1}^{N}\sum_{k=1}^{8}\log p(\mathbf{x}_{nk}^{GT})\]
\[\mathrm{Coverage}_\alpha=\frac1{8N}\sum_{n,k}\mathbf1[\mathbf{x}_{nk}^{GT}\in A_{nk,\alpha}],\quad A_\alpha=\{\mathbf{x}:p(\mathbf{x})\ge c_\alpha\}\]

ADE/FDE는 원본 confidence 최상위 대표 경로의 오차(m)입니다. NLL은 시점별 위치 density(nats), minADE/minFDE는 GT로 후보를 고르는 oracle 지표입니다. HDR은 밀도 수준 집합이며 MC 2,500개/시점과 120×120 grid로 계산합니다. 유효 GT가 같은 origin끼리 비교합니다.

Coverage는 정답을 포함하는 비율, Sharpness는 영역의 크기입니다. 95% HDR 면적(m²)이 작아도 목표 Coverage를 만족하지 못하면 좋은 UQ라고 할 수 없습니다.

Geometry의 거리와 시간

\[s=(\mathbf{x}-\mathbf{c})^\top\mathbf{a},\quad\ell=(\mathbf{x}-\mathbf{c})^\top\mathbf{n},\quad d_{exit}=\max(0,d[s_{exit}(\ell)-s])\]

d는 횡단 방향 ±1입니다. 남은 거리는 현재 lateral 위치에서 semantic Exit까지의 횡단축 방향 거리이며 실제 향후 보행 경로 길이가 아닙니다. 구역 측면을 벗어나면 계산을 보류합니다. semantic 경계 간 길이는 지도 추정값이며 실측 전체 횡단보도 길이와 구분합니다.
