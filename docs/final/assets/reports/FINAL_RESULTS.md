# View2Risk — FINAL_RESULTS (최종 품질 점검판)

## 적용 범위와 수정 기록

새 학습·새 데이터·GPU 잡·기능 확장은 없다. 기존 17개 사례, 153개 origin, 8조건을 유지했다. IMPTC는 54 origin / 6 events / 3 recordings(2개 날짜), inD는 99 origin / 11 tracks / 11 recordings이다. 이 고정 소규모 탐색 결과를 전체 데이터셋의 일반화 성능으로 해석하지 않는다. 같은 이벤트의 반복 origin은 독립 표본이 아니다.

inD adapter의 exact RGB 매칭이 원본 `(70,70,70)` 장애물을 누락했다. 공식 코드의 사전 정의는 `(70,70,71)`이지만 실제 전처리는 채널별 매칭 후 red-channel을 사용하여 장애물을 유지한다. 공식 방식으로 복구하고 동일 99개 origin × 8조건 = 792개 결과를 재계산했다. 예시 03번 지도에서 742,497개 blocking 픽셀이 영향을 받았다. 좌표축·시간·가중치·seed·R·q_filter·prior·MC 수는 그대로다. IMPTC의 전처리는 이미 공식 방식이므로 변경하지 않았다.

또한 R+Q의 평균 표시 이력에 마지막 샘플의 회전이 붙어 있던 메타데이터를 정정했다. 평균 표시 경로에는 단일 회전을 부여하지 않고 `rotation=null`, 실제 8개 조건부 입력은 `input_contexts`에 기록한다. 이 메타데이터 수정은 예측값에 영향을 주지 않는다. 수정 전 결과/코드/사례는 `reports/release_qa_20261110/before/`에 보존했다.

원본 JSON의 120,871 windows 결과를 재사용했다. 전체 Test 재실행은 하지 않았다.

## R+Q 원인 분석

### 위치 차분의 잡음 증폭

Train R의 위치 표준편차는 X=0.156835m, Y=0.177521m이다. 독립 위치잡음을 0.1초 간격으로 차분하면 `Cov(δv)=2R/dt²`, 두 번 차분하면 `Cov(δa)=6R/dt⁴`이다. 예상 2D 속도 RMS 잡음은 3.349953m/s, 가속도 RMS는 58.022891m/s²다. 실제 같은 합성 관측의 평균 값은 다음과 같다. 이 값은 **과거 입력의 변화량**이며 미래 예측 오차가 아니다.

|---|---|---|---|---|---|---|

DD-MDN 실제 encoder는 위치·속도·가속도 6개 특징을 사용한다. 마지막 유효 0.1초 변위로 정하는 heading도 잡음에 민감하다. 회전 자체는 올바르지만 잡음으로 heading이 바뀌면 지도 crop·회전과 상대 객체 표현도 함께 바뀐다. Test를 보고 heading 평활화나 필터 파라미터를 선택하지 않았다.

### 필터·FFBS·좌표 검증

- R 원본 hash, m² 단위, PSD, bias 처리, moment RMSE를 확인했다. SPD→IMPTC/inD 축 전이는 물리적으로 보정된 변환이 아니라 가정이다.
- 상태 `[x,y,vx,vy]`, q_filter=0.5m²/s³, dt=0.1초의 Q_delta를 독립 수식과 대조했다. 위치 process variance는 축당 0.000166667m²/step, 속도 variance는 0.05(m/s)²/step이다.
- 초기 속도 공분산 trace 50(m/s)²가 10개 관측 후 약 0.343432로 줄었다(초기 대비 0.6869%). 위치의 2D posterior SD는 0.152873m, 속도는 0.586031m/s. 마지막 0.4초 누락에서는 각각 0.448208m와 0.943569m/s다. 초기 분산이 그대로 폭발한 것은 아니지만 prior와 q의 경험적 적합성은 검증되지 않았다.
- FFBS를 전체 선형 Gaussian의 batch conditioning과 비교한 평균 오차는 8.49e-12m, 10,000개 검사 샘플의 최대 공분산 차이는 0.000165m² 이하였다. 이는 수학 단위 검사이며 실제 데이터 성능으로 보고하지 않는다.
- 실제 153개 origin의 잡음·필터·FFBS 과거 이력을 같은 seed로 정확히 재생성했다. 두 사전 고정 사례의 Clean/Noisy/Filtered mean/R+Q 분포·가설은 재추론 결과와 일치했다. 회전 역변환, 공분산 회전, 지도 좌표 방향도 검사했다.
- 공식 inD raster의 물리 crop 폭은 recording 0~6에서 약 36.576m, 나머지에서 약 23.461m다. nominal coordinate grid의 20m와 다르지만 공식 checkpoint가 사용하는 전처리를 그대로 유지했다. 이번에 Test를 보고 재보정하지 않았으며 upstream 표현상의 한계로 기록한다.

### 실제 두 사례의 단계별 비교

위 표는 total covariance 법칙의 조건부 분산과 조건부 평균의 분산이다. 서로 다른 물리 원인의 정확한 기여 비율이 아니다. R+Q에서는 과거 샘플 간 평균 차이뿐 아니라 각 샘플에 조건화한 DD-MDN 분포 자체의 폭도 커진다. 원본 모델이 이미 포함한 annotation noise와 추가 R이 중복되는지는 독립 잠재 GT 없이 분리할 수 없다. q·prior·MC 수를 변경하지 않았고, Clean 회복을 주장하지 않는다.
