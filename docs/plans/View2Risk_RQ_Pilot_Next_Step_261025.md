## 0. 이전 MD를 다시 실행하지 말 것

기존 `View2Risk_Data_Audit_Plan.md`의 **A. 샘플 확보·무결성, B. 스키마 및 Parquet, C. 샘플 품질 감사, D. 후보 요소 정리**는 `sample_audit_261025.md`에 샘플 기준 완료된 것으로 보고되어 있다. 전체 데이터셋 다운로드나 이미 실행한 감사 작업을 반복하지 않는다.

이번 문서는 **새로운 다음 단계**를 지시한다. 원본·기존 결과는 보존하고 새 결과는 별도 폴더에 저장한다. 결과가 재현되지 않으면 기존 결과를 덮어쓰지 말고 불일치 내용을 기록한다.

## 1. 용어와 현재 데이터 규모

- **트랙(track):** 같은 시퀀스 안에서 동일 객체 ID에 연결된 시간별 위치 기록. 여러 프레임이 있어도 여러 명으로 세지 않는다. 트랙 ID 그룹이 서로 다른 실제 사람을 항상 뜻하는 것도 아니다.
- **SPD Example:** 1개 시퀀스, 251프레임, **9개 보행자 트랙 그룹**, camera ↔ virtual-LiDAR 대응 주석 **253쌍**. 253쌍을 독립된 보행자 253명으로 간주하지 않는다.
- **IMPTC Samples:** 4개 시퀀스, 61개 트랙, 56,374 관측. `status=2` 유효 관측 54,314개, 유효 구간이 **10초 이상인 트랙 49개**.
- **R (관측 불확실성):** 측정값과 실제 상태 사이의 오차. 이번 SPD에서는 **camera-side와 virtual-LiDAR-side 주석 간 불일치**만 관측되므로 `R_pair_proxy`로 명명한다. 순수 카메라 모델 오차 또는 정답 `R_camera`라고 부르지 않는다.
- **Q (움직임 불확실성):** 정해진 움직임 모델(CV 등)로 설명되지 않는 실제 상태 변화의 과정 잡음. IMPTC 제공 궤적도 추적·측정 결과이므로 단순 예측 잔차의 공분산을 곧바로 참값 `Q_true`라고 부르지 않는다.
- **B (사람 간 속도 차이):** 초기 속도의 분포/보조 변수다. 별도의 핵심 UQ 개발 대상이 아니다.
- **신호:** 현재 파일럿에서는 **사용하지 않는다.** IMPTC의 f1/f2/f3는 어느 보행자에게 적용되는 신호인지 공간 매핑이 미검증이기 때문이다. 횡단보도 시간 G95 또한 이번 단계에서 계산하지 않는다.

## 3. R 파일럿 — SPD 주석 쌍의 불일치 모델

### 3.1 데이터 준비·기존 계산 재현

1. `spd_pedestrian_pairs.parquet`의 실제 컬럼을 확인한다. `sequence_id`, `track_id`, 카메라/virtual-LiDAR 위치, 각 센서 timestamp, occlusion, 거리 등이 어떻게 저장되었는지 표로 정리한다.
2. 같은 객체, 일치하는 좌표 기준, timestamp 단위를 확인한다. 기존 보고서는 timestamp가 **UNIX epoch 마이크로초**라고 기록했다.
3. `sample_audit_261025.md`의 수평 위치 차이 RMSE **0.185183m**, 중앙값 **0.135995m**를 재현한다. 차이가 있다면 산식·샘플 필터·좌표 변환을 확인한다.
4. **calibration 유의:** 기존 보고서에서 제공 virtual-LiDAR→camera 행렬의 직교 회전 조건이 성립하지 않았고 투영 검사도 불일치했다. 원본 행렬을 임의로 교정하거나 정상이라고 전제하지 말고, 이미 동일 좌표계라고 문서화된 3D 주석 쌍을 중심으로 계산한다. 변환/투영 관련 미해결 사항을 명시한다.

### 3.2 추정할 값

동일한 기준 좌표계에서의 수평 벡터 차이를 `e_t=(dx_t,dy_t)`로 놓고 다음을 구한다.

- 평균 편향 `mean(e)` (m)
- `Cov(e - mean(e))`의 2×2 행렬 (m²): **`R_pair_proxy`**
- `||e||`의 median, RMSE, p90/p95와 경험적 히스토그램
- `track_id`별 요약 및 시간 자기상관(가능한 경우)
- `timestamp_gap`과 잔차 크기의 관계(진단용)
- 조건 후보(거리·가림)는 **시각화만** 하고 샘플 9트랙으로 조건부 모델 우수성을 주장하지 않는다.

기본 비교: (a) 편향 없는 Gaussian, (b) 편향 포함 Gaussian, (c) 경험적 bootstrap 샘플링. 후자는 표본이 작으므로 시연용이다.

### 3.3 R 검증 범위

- 트랙 단위로 resampling/holdout을 한다(프레임 단위 무작위 분할 금지).
- 관측 오차 분포의 크기·편향·꼬리·시간 상관을 보여준다.
- **단일 교차로·9트랙만으로 외부 일반화 또는 순수 카메라 모델의 오차 정답을 검증했다고 주장하지 않는다.**
- 만약 좌표 변환의 타당성이 추가로 불확실하면 `R_pair_proxy`는 시연용 진단으로만 유지한다.

## 4. Q 파일럿 — IMPTC 샘플의 움직임 모델 잔차

### 4.1 데이터 분리·기본값

1. `stage_samples/imptc_pedestrian_tracks.parquet`의 실제 컬럼/단위 확인.
2. `sequence_id + track_id`를 하나의 그룹으로 묶고 `status=2`, 유한 좌표, `0 < dt <= 0.060s`인 연속 구간을 기본으로 사용한다.
3. 관측 간격 중앙값은 약 **0.040009초**. 속력 필드는 **km/h이므로 m/s로 변환**하고, 단위와 방향 성분 여부를 명시한다.
4. **4개 시퀀스를 기준으로 holdout**한다. 권장: leave-one-sequence-out(한 번에 1개 시퀀스 테스트, 3개 시퀀스 개발). 한 트랙의 앞부분을 학습·뒷부분을 테스트로 넣어 시퀀스 종속성을 숨기지 않는다.
5. 장면마다 속도 분포가 다를 수 있으므로 전체 평균만 보지 말고 시퀀스별·트랙별 요약을 남긴다.

### 4.2 기본 움직임 모델

우선 2D Constant Velocity(CV) baseline 하나를 구현한다.

- 상태: `z_t=[x_t, y_t, vx_t, vy_t]ᵀ`
- 예측: `z_(t+Δt) = F(Δt) z_t + w_t`
- `F`는 등속도 전이 행렬. `Q`는 시간간격 단위를 일치시켜 공분산 또는 소수 파라미터를 갖는 가속도 잡음 모델로 나타낸다.
- 1초 및 3초 예측 horizon에 대해 기준 궤적과의 **예측 위치 잔차**를 먼저 계산한다. 25Hz의 1프레임 잔차만으로 Q를 추정하면 수치 미분·관측 잡음에 민감할 수 있다.
- `velocity`가 위치 차분에서 파생된 값일 수 있으므로 위치와 속력을 독립된 정답 둘로 취급하지 않는다.

### 4.3 '잔차'와 '순수 Q'를 구분할 것

초기 산출물은 `Q_effective` 또는 `motion_model_residual`로 기록한다.

- 위치 관측의 잡음 때문에 잔차가 커지는지, 서로 다른 평활화 강도에서 분산이 어떻게 변하는지 민감도 분석한다.
- 가능하면 IMPTC **자체 궤적만으로** 상태공간모델의 관측 잡음과 과정 잡음을 함께 추정하는 EM/Kalman baseline을 추가한다. 이때도 R/Q가 유일하게 식별되었다는 주장은 하지 않는다.
- 본 단계에서 SPD의 `R_pair_proxy`를 **IMPTC의 참 관측 R처럼 강제로 넣지 않는다.** 센서·도시·데이터 처리 체계가 다르기 때문이다.
- 원한다면 별도의 **가정 기반 민감도 실험**으로만 IMPTC 궤적에 SPD와 비슷한 크기의 인공 관측 잡음을 주입한다. 이때 '실제 통합 검증'이라고 부르지 않는다.

### 4.4 조건 변수 (이번 파일럿의 범위 제한)

- **우선 분석:** 속도, 가속·감속, 정지/재출발, 방향 전환. 행동 분류는 기존의 임계값을 후보로만 사용하며 확정 GT처럼 사용하지 않는다.
- **통제 변수:** `source_type`(LiDAR/fusion/camera), `status` — 센서 전환과 움직임의 효과가 뒤섞이지 않는지 확인한다.
- **선택:** 주변 보행자 수(5m 동시 추적 수)는 진단적으로만 분석한다.
- **제외:** `signal_f1/f2/f3`, 날씨의 조건효과, 연령, 신호 위반. 샘플에서 대응·변화·표본 근거가 부족하다.

## 5. 파일럿 검증 — '불확실성을 제대로 추정했는가?'

**서로 다른 두 질문을 분리한다.**

1. `R_pair_proxy`가 실제 SPD 주석 간 잔차의 분포를 설명하는가? (잔차 편향·중앙값·꼬리·시간 상관)
2. `Q_effective`를 이용한 미래 궤적의 **예측 분포가 독립된 IMPTC 시퀀스의 기록된 궤적을 얼마나 잘 포함하는가?** (coverage와 sharpness)

IMPTC 궤적은 독립적인 물리적 참값이 아니라 제공된 추적 궤적이므로, 2번은 **recorded-trajectory 기준 대리 검증**이다.

필수 비교(같은 데이터분할·horizon에서):

| 모델 | 의미 |
|---|---|
| Deterministic CV | 점 예측 기준선 |
| Fixed noise state-space | 개발용 시퀀스에서 선택한 고정 관측/과정 잡음 |
| Data-fitted Q state-space | 훈련 시퀀스에서 추정한 효과적 과정 잡음, 동일 평가 |

- 1초·3초 미래 위치 RMSE/MAE
- 목표 90%·95% 위치 예측영역의 **실제 포함률**
- 예측영역의 면적 또는 반경(무조건 넓혀서 포함률만 높이는 문제 방지)
- Gaussian 가정의 적합성 및 극단값 실패 사례
- NIS 등 innovation consistency를 사용했다면 그 해석 한계: NIS만으로 개별 R/Q의 정답을 입증할 수 없다.
- 각 평가의 **테스트 시퀀스 수(최대 4), 트랙 수, 예측 건수**를 분리해 표시한다. 프레임 수를 독립 실험 수로 해석하지 않는다.

가능하면 모델 설정을 튜닝할 개발/검증 시퀀스와 최종 평가 시퀀스를 명확히 구분한다. 4개 시퀀스로는 안정적 모델 선정과 일반화 주장에 한계가 있음을 명시한다.

## 6. 결과 보고 형식과 완료 조건

최종 `pilot_summary.md`에는 반드시 다음을 넣는다.

1. **현재 데이터 범위:** SPD 1 시퀀스·9트랙·253쌍 / IMPTC 4 시퀀스·61트랙과 유효 구간 수.
2. **R 결과:** 주석 간 차이의 편향, `R_pair_proxy` 공분산 행렬, 꼬리, 시간 상관; coordinate/calibration 한계.
3. **Q 결과:** CV 1초/3초 잔차분포, `Q_effective` 추정 방식과 단위/Δt, 개인·시퀀스 간 차이 및 관측 잡음 민감도.
4. **검증:** 홀드아웃 시퀀스별 coverage + 영역 크기 + RMSE/MAE, 실패 사례.
5. **판정:** (A) 샘플에서도 R/Q 파일럿 가능 / (B) 추가 R 라벨 우선 / (C) 추가 Q 궤적 우선 / (D) 실측 GT 부족으로 통합 주장 보류 — 근거를 적는다.
6. **재현성:** 코드 실행 명령, 입력 경로, 라이브러리 버전, random seed, 생성 파일 목록 및 입력 해시.
