# View2Risk 진행 정리 — 횡단보도별 필요 보행시간 G*(p)

작성일: 2026-11-02 · 데이터: 조원 repo [riverblue72/view2risk](https://github.com/riverblue72/view2risk) (Releases `data-261026`, analysis preset)

---

## 1. 목표

### 1.1 프로젝트
카메라 인식 오차와 보행자 움직임 오차를 고려한 **횡단보도 신호 최적화** (View2Risk)

### 1.2 이번 방향
보행을 **마치는 시간**을 기준으로 **횡단보도마다 건너는 데 필요한 최적의 시간**을 도출한다.

### 1.3 이번 주 목표
1. 횡단보도 획일화: 입력과 출력을 명확히 정의
2. 데이터 정리
3. 수학 모델 만들기

### 1.4 변수 범위
- 주요 변수: 카메라 인식 오차(R), 보행자 흔들림(Q)
- 보조 변수: 날씨, 여러 명이 함께 건널 때의 속도 저하

### 1.5 다시 정리한 목표 (결과를 반영)
> **카메라로 측정한 보행 완료시간으로 횡단보도별 필요 보행시간을 정할 수 있는가, 그리고 그 값은 무엇에 가장 크게 좌우되는가?**

| 축 | 역할 |
|---|---|
| 측정 가능성 (R) | 카메라 오차가 있어도 G\*를 정할 수 있는가, 어떤 종류의 오차가 위험한가 |
| 지배 요인 | 보행자 사이의 속도 차이와 횡단보도 길이 |
| 적용 | 현재 신호가 필요 시간보다 짧은 곳 찾기 (예: f2) |
| 흔들림 (Q) | 정적 G\*가 아니라, 점멸 시점에 건너고 있는 사람이 완료할 수 있는지 실시간 예측하는 확장 기능 |

## 2. 입출력 정의 (횡단보도 획일화)

**횡단보도 단위**
- `signal_group` (f1/f2/f3), 길이 L, 폭, 중심 **c**, 횡단 방향 축 **u**
- 출처: 공식 IMPTC 지면 지도 → 조원 repo `geometry.csv`

| 횡단보도 | 길이 L | 폭 |
|---|---|---|
| f1 | 10.9m | 3.9m |
| f2 | 15.8m | 3.9m |
| f3 | 10.0m | 3.7m |

**입력 (보행자 1명 × 횡단 1회 = 이벤트 1개)**
- 진입 시각, 이탈 시각, 분류(완료 / 중도절단 / 도착확인부족 / 되돌아감)
- 진입 시 신호 코드, 날씨, 반경 5m 내 주변 보행자 수
- 녹색 시작·종료 시각 (신호 기록에서 추출)

**출력 (횡단보도 1개)**
- G\*(p): p% 보행자가 건너기를 마치는 데 필요한 보행시간, 95% 신뢰구간
- 국내 공식 값, 현재 녹색 시간과의 비교

**'완료'의 정의**: 조원 repo의 사전 고정 규칙(base)을 그대로 썼다. 양 끝 경계를 반대편까지 통과해야 하고, 시작·끝에 보도 착지가 0.12초 이상 관측돼야 하며, 경로의 95% 이상이 횡단보도 안에 있어야 한다.

## 4. 수학 모델

| # | 단계 | 식 | 비고 |
|---|---|---|---|
| 1 | 횡단보도 기하 | 지도 횡단보도 점 → PCA 축 **u**, 중심 **c**, 길이 L | 조원 repo |
| 2 | 소요시간·속도 | T = t_exit − t_entry, v = L / T | 완료 이벤트 |
| 3 | 녹색 시작 | t_on = (t_{k−1} + t_k) / 2 (신호 10→4 전환) | 1Hz → ±0.5s |
| 4 | 진입 지연·완료시간 | D = t_entry − t_on, C = t_exit − t_on | 녹색 진입 이벤트 |
| 5 | 소요시간 분포 | Kaplan–Meier Ŝ(t) = ∏_{tᵢ≤t}(1 − dᵢ/nᵢ), Q_p = inf{t : 1 − Ŝ(t) ≥ p} | 중도절단 = 하한값 |
| 6 | **필요 보행시간** | **G\*(p) = 7s + Q_p(T)** | 국내 공식 7 + L/v 와 같은 형태 |
| 7 | 신뢰구간 | 촬영일 단위 cluster bootstrap 1,000회 | |
| 8 | 카메라 오차 전파 | T̃ = T + (e₁ − e₂) / v, e ~ N(0, σ²) 또는 SPD 경험분포 | σ = √(tr R / 2) = 0.21m |
| 9 | 보조 변수 | 층별 중앙값, Spearman ρ(v, 주변 보행자 수) | |
| 10 | 차량 측 trade-off | g = C − G\* − 4, x = (q/s)/(g/C), d = 0.5C(1 − g/C)² / (1 − min(1, x)·g/C) | Webster/HCM 균일지연, q/s는 가정 |
| 11 | 미완료자 속도 | s = (**p** − **c**)·**u**, v_axis = \|s_end − s_start\| / Δt, T̂ = L / v_axis | 관측 ≥2s, 이동 ≥2m |

**Q를 쓰지 않은 이유**: 측정된 소요시간 T에는 실제 흔들림과 속도 변화가 이미 들어 있다. Q를 오차로 다시 더하면 같은 효과를 두 번 세게 된다.

R은 V2X-Seq(중국), 이벤트는 IMPTC(독일)에서 나왔으므로 R은 보정값이 아니라 **"카메라로 측정했다면"이라는 시나리오**로만 썼다.

## 5. 결과

### 5.1 횡단보도별 필요 보행시간

| 횡단보도 | 중앙 속도 | 하위 15% 속도 | Q85 소요 (95% CI) | **G\*(85%)** | **G\*(95%)** | 국내 공식 1.0 / 0.8 m/s | 실측 녹색 |
|---|---|---|---|---|---|---|---|
| f1 (10.9m) | 1.48 m/s | 1.30 m/s | 8.5s (8.3–8.7) | **15.5s** | **16.1s** | 17.9 / 20.6s | 중앙 46s (가변) |
| f2 (15.8m) | 1.56 m/s | 1.38 m/s | 11.6s (11.4–11.9) | **18.6s** | **19.8–20.4s** | 22.8 / 26.7s | **14s 고정** |
| f3 (10.0m) | 1.44 m/s | 1.22 m/s | 8.3s (8.0–8.7) | **15.3s** | **16.2s** | 17.0 / 19.5s | 중앙 43s (가변) |

- 관측된 신호 주기는 약 86~91초다.
- f2의 G\*(95%) 범위는 미완료자 처리 방식에 따라 달라진다. 속도 환산이면 19.8s, KM 하한 처리면 20.4s다.

### 5.2 핵심 관찰

1. **f2는 녹색이 부족하다.** 녹색은 14s인데, 녹색 직후 출발한 무리(진입 지연 ≤7s)의 완료시간이 85% 기준 16.5s, 95% 기준 18.1s다. 녹색에 진입한 사람의 **77%가 녹색이 끝난 뒤에** 건너기를 마쳤다(초과시간 95% 분위 6.7s). 독일식 신호는 녹색 뒤 적색 정리시간에 건너기를 마치는 구조다. 한국식 '녹색+점멸' 기준으로 보면 세 곳 중 가장 부족한 곳이다.
2. **국내 공식(1.0m/s)이 실측 95% 분위보다 1~2.4s 길다.** 하지만 이 데이터는 독일 보행자이고 연령을 구분할 수 없다. 하위 15% 속도도 1.22~1.38m/s로 높다. 따라서 "국내 공식이 과하다"는 결론을 내리면 안 된다.
3. **f1·f3는 녹색이 길다(약 45s).** 진입 시점이 녹색 전체에 퍼져 있다(진입 지연 85% 분위 약 26~27s). 녹색이 끝난 뒤 완료한 비율은 8~10%다.

## 6. 보완 분석: 다 건너지 못한 사람들

### 6.1 처음 처리 방식의 한계
- 속도(m/s) 통계와 카메라 오차·보조 변수 분석은 **완료자만** 사용했다.
- G\*에서는 중도절단자를 "최소 이만큼 걸렸다"는 하한값(KM)으로만 넣었다. 이들의 관측시간 중앙값은 2.8~4.7s로 짧아서 분포 상단에는 거의 영향이 없었다.
- 미완료자가 더 느린 사람이라면 G\*가 실제보다 짧게 나왔을 위험이 있었다.

### 6.2 방법
- 횡단보도 위 관측 구간의 궤적을 횡단 축에 투영해서 v_axis = 축 방향 이동거리 ÷ 관측시간을 구했다.
- **방법 검증**: 완료자에게 같은 방법을 적용하면 기존 L/T 대비 비율 중앙값이 1.000 (IQR 1.000–1.004)이었다.

### 6.3 결과

| 횡단보도 | 완료자 중앙 속도 | 중도절단 중앙 속도 (사용/전체) | 차이 검정 p | G\*(95%): 완료만 → +중도절단 → +도착확인부족 |
|---|---|---|---|---|
| f1 | 1.50 m/s | 1.45 m/s (41/46) | 0.12 | 15.9 → 16.1 → 16.2s |
| f2 | 1.56 m/s | 1.50 m/s (177/229) | <0.001 | 19.7 → 19.8 → 19.8s |
| f3 | 1.44 m/s | 1.44 m/s (64/101) | 0.32 | 16.1 → 16.3 → 16.3s |

- 미완료자는 약간 느린 경향이 있다. 유의한 곳은 f2뿐이고, 중앙값 차이는 0.06m/s다.
- G\*(85~95%) 변화는 **0.2s 이하**로 신뢰구간 안에 든다. 결론은 바뀌지 않는다.
- 속도를 낼 수 없어 제외된 미완료자는 94명(관측 <2s 또는 이동 <2m)이고, 되돌아간 6명도 제외했다.

## 7. 카메라 인식 오차(R) 재검토

### 7.1 R의 실제 크기 (V2X-Seq SPD)

| 조건 | RMSE | 95% 분위 |
|---|---|---|
| 전체 | 0.30m | 0.48m |
| 센서 근거리 (~69m) | 0.17m | 0.33m |
| 센서 원거리 (88m~) | 0.45m | 0.81m |
| 최대 | 7.1m | |

주의: R은 **카메라 주석과 LiDAR 주석의 차이**다. 실제 검출기 오차가 아니며, 검출 누락·ID 전환·야간·악천후는 거의 반영되지 않았다. 따라서 실제 카메라 오차를 과소평가하고 있을 가능성이 크다.

### 7.2 기본 R의 영향이 작았던 이유
1. 위치 오차 0.21m ÷ 보행속도 1.5m/s ≈ 진입·이탈 시점당 0.14s
2. 사람마다 무작위인 작은 잡음이, 훨씬 큰 사람 간 속도 차이에 묻혀 분위수가 거의 움직이지 않는다.
3. 모든 위치가 같은 방향으로 밀리는 일정한 치우침은 진입과 이탈에서 상쇄된다.

### 7.3 스트레스 테스트 (G\* 분위수 변화, 3개 횡단보도 범위)

| 시나리오 | Q85 변화 | Q95 변화 |
|---|---|---|
| 기존 R (σ 0.21m) | +0.01 ~ +0.03s | +0.01 ~ +0.12s |
| 원거리 수준 (σ 0.32m) | +0.04 ~ +0.06s | +0.05 ~ +0.21s |

| 5% 이벤트만 큰 오류 (σ 1.5m) | +0.04 ~ +0.08s | +0.07 ~ +0.23s |

### 7.4 결론
> 카메라의 **무작위 위치 오차**는 필요 보행시간에 거의 영향을 주지 않는다. 대신 **캘리브레이션(거리 축척) 오류**와 **느린 보행자의 검출 누락**은 G\*를 0.5~1.3s 틀어지게 할 수 있다. 특히 검출 누락은 신호를 **짧게** 만드는, 안전하지 않은 방향의 오류다.

이 결론은 '인식 오차' 축을 없애는 것이 아니라 **어떤 종류의 인식 오차를 관리해야 하는지**를 구분해 준다. 조원 repo도 SPD 카메라 행렬이 정규직교가 아니라는 보정 문제를 미해결로 기록해 두었다.

## 8. Trade-off 곡선

- **보행자 측 (실측)**: 녹색 안에 못 끝내는 비율 1 − p ↔ G\*(p)
- **차량 측 (가정)**: 실측 주기 90s, 손실시간 4s, 교통량/포화교통류율 비 q/s = 0.2 / 0.3 / 0.4 시나리오, Webster/HCM 균일지연
- IMPTC 분석 데이터에는 차량 궤적이 없어서 차량 측은 가정값이다. 차량 데이터를 확보하면 실측값으로 바꿀 수 있다.
- 파일: `tradeoff.csv`, 그림 `gstar_overview.png` ③

## 9. 한계

1. 교차로 1곳(독일 Aschaffenburg), 횡단보도 3개만 다뤘다. 일반화는 길이 L에 대한 관계식 수준으로만 주장할 수 있다.
2. 연령·보행보조 여부를 구분할 수 없어 취약 보행자 기준(0.8m/s)을 직접 검증할 수 없다.
3. '완료'는 지도 기반 운영 규칙이며, 사람이 직접 확인한 정답 라벨이 아니다.
4. 신호가 1Hz라서 녹색 시작 시각에 ±0.5s 해상도 한계가 있다.
5. R은 주석 간 차이로 만든 대리값이다. 실제 검출기 오차가 아니다.
6. 독일식 신호(녹색 → 적색 정리)와 한국식 신호(녹색 + 점멸)는 구조가 다르다.
7. 차량 측 trade-off는 가정값 시나리오다.
8. 속도를 추정할 수 없는 미완료자 94명과 되돌아간 6명은 제외했다.
