## 데이터와 범위

- **R / SPD:** 인프라11,275프레임을 확인하고, 6교차로·233시퀀스-트랙 그룹의 대응 주석10,109쌍을 분석했다. 교차로 단위 홀드아웃을 사용했다.
- **Q / IMPTC:** Full Sequence Sets01–05, 270시퀀스 중 보행자가 있는264시퀀스,1,920트랙·1,710,765관측을 감사했다. 공통1초/3초 예측 시작점265,578개, 평가 가능한1,906트랙을15촬영 날짜 단위5-fold로 평가했다.
- **TFD:** Example 단일 infrastructure view만 별도 감사했다. Full TFD 분석이 아니다.

R 주석 차이의 RMSE는0.299m였다. Data-fitted Q의 결과는 다음과 같다.

| 예측 시점 | 위치 RMSE | 목표95% 영역의 실제 포함률 | 평균95% 영역 면적 |
| --- | ---: | ---: | ---: |
| 1초 | 0.165m | 94.10% | 0.331m² |
| 3초 | 0.914m | 90.43% | 7.038m² |

추가 감사에서는 지도와 연속 관측 규칙으로 **완료846이벤트 /787트랙**을 집계하고 f1/f2/f3 신호를 공간·시간 연결했다. 횡단보도 접촉이 있으나 완료 규칙을 충족하지 못한379트랙, 유효 지도 접촉이 없는754트랙을 별도로 보존했다.

## 해석상 제약

- `R_pair_proxy`는 camera/virtual-LiDAR **주석 간 차이**이며 카메라 검출기의 실제 오차가 아니다.
- `Q_effective`는 제공된 추적 궤적 기준이다. 독립 물리 참값이나 R/Q의 유일한 식별을 주장하지 않는다. 3초95% 예측영역은 실제 포함률90.43%로 과소 포괄한다.
- 완전/부분 횡단은 지도 기반 운영 규칙이다. 독립 manual GT로 검증한 분류 정확도가 아니며 경계 민감도가 있다.
- 신호는 공식 도식·지도 원점/topology로 연결했다. 빨간 신호 기록의 진입을 검증된 법적 위반 정답으로 간주하지 않는다.
- 공식 코드의 `cam_K` 투영 규약은 확인했다. 원본 카메라 행렬 nonrigidity의 생성 원인은 미해결이다.
- 과거 HTML의 `q≈0.05`는 원래 산식/선정 코드가 없어 정확 재현하지 않았다. G95·신호 최적화는 이번 MD 범위에서 제외했다.
- 이전 샘플/Set01을 열람한 뒤 수행한 전체 확장판으로, 탐색적 OOF 결과다. 독립 미열람 외부 Test 일반화를 주장하지 않는다.
