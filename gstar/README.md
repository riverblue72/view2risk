## 분석 경과 요약

### 1. G*(p) 도출 (11/2)
- G*(p) = 7초 + Q_p(T). T는 완료 이벤트 소요시간, Kaplan–Meier로 중도절단 포함, 촬영일 단위 bootstrap.
- G*(95%): f1 16.1s, f2 19.8–20.4s, f3 16.2s. f2 실측 녹색은 14s로 부족하다.
- 미완료자 속도를 궤적으로 추정해 넣어도 G*(95%) 변화는 0.2s 이하.
- 카메라 무작위 오차 R은 영향이 거의 없다(+0.01~0.12s). 거리 축척 오차(±3~5% → ±0.3~0.6s)와 느린 보행자 검출 누락(최대 −1.25s)이 위험하다.

### 2. 시간대·요일·연령 (11/5, `analysis/time_weekday.py`)
- 시각은 IMPTC 타임스탬프를 Europe/Berlin 현지시각으로 변환해 썼다.
- 시간대(아침 7–9 / 점심 11–13 / 오후 15–17): 중앙 속도 1.48~1.51 m/s, G* 차이 0.5s 이내. 보행량(점심 148건/h)과 적색 진입(오후 8.3%)만 다르다.
- 요일: 요일별 촬영일이 1~3일이라 촬영일 효과와 구분할 수 없다. 주장하지 않는다.
- 연령: IMPTC와 V2X-Seq 모두 연령 라벨이 없다. `signal_age_s`는 사람 나이가 아니라 신호 기록이 몇 초 전 값인지를 뜻한다.

### 3. 서울시 보행신호 자료 반영 (11/7)
- 신호 운영은 시간대(±1s)·요일(같은 교차로 차이 중앙값 0.0s)과 거의 무관하다. → G*는 횡단보도별 값 하나로 정해도 된다.
- 신호 전환 시점 오차 σ 0.44s로 관측 해상도 수준이다. → G*를 좌우하는 것은 보행자 간 속도 차이와 횡단 길이라는 결론이 신호 쪽에서도 확인됐다.
- 서울 교차로·방향 4,779쌍의 보행 가능 총시간 히스토그램으로, 필요 시간 7초 + L/v보다 짧은 비율을 속도 시나리오별로 계산했다(20m: IMPTC 95% 속도 1.15 m/s → 17%, 1.0 m/s → 27%, 0.8 m/s → 52%).
- 서울 점멸 중앙값 15s로 녹색 끝 진입자가 건널 수 있는 최대 길이: 1.15 m/s 17.3m, 1.0 m/s 15m, 0.8 m/s 12m.
- 서울 참고자료 7절은 필요 시간을 L/v로만 계산했다. 7초를 포함하는 기준으로 통일할 것을 제안한다.

## 다음 분석 추천 (자세한 내용은 HTML 5절)
- **R**: 실제 검출기 오차·누락률 측정(SPD 이미지), 느린 보행자 누락 여부, 거리 축척 오차 정량화, 조건부 R(yizhuang10 포함률 61% 원인), 진입·이탈 오차 상관.
- **Q**: 녹색 종료 시점 완료 가능성 예측과 실측 비교, 3초 예측영역 과소포함(90.4%) 보정, 상황별 q. Q는 G*에 다시 더하지 않는다(이중 계산).
- **공통**: 서울 횡단보도 길이 연결, 7초 + L/v 기준 통일, 국내 연령별 보행속도 근거 확보.
