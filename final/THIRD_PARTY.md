# Third-party sources

- [DD-MDN](https://github.com/kav-institute/ddmdn), [paper](https://arxiv.org/abs/2602.11214), official code/checkpoints external, pinned commit in README. Follow upstream licensing; no weights vendored.
- [PedPy](https://github.com/PedestrianDynamics/PedPy): pedestrian dynamics, upstream MIT.
- [FilterPy](https://github.com/rlabbe/filterpy): Kalman filtering, upstream MIT.
- [inD Tools](https://github.com/ika-rwth-aachen/drone-dataset-tools): licensed-data loader, upstream license applies; not vendored.
- [V2X-Seq](https://github.com/AIR-THU/DAIR-V2X-Seq): SPD annotation disagreement proxy; aggregate statistics only.
- [Babylon.js](https://github.com/BabylonJS/Babylon.js): Apache-2.0, bundled license in `docs/final/assets/vendor/BABYLON-LICENSE.txt`.
- [KaTeX](https://github.com/KaTeX/KaTeX): MIT, bundled license in `docs/final/assets/vendor/katex/LICENSE`.
- IMPTC dataset: CC BY-NC 4.0, see DATA_POLICY.md. Dataset and code licenses are distinct.

This project integrates existing methods; it does not claim invention of DD-MDN, Kalman filtering, FFBS or Monte Carlo.
