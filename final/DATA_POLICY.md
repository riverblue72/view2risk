# Public data policy

The public site includes three short IMPTC-derived replay excerpts and actual precomputed DD-MDN outputs, attributed to the IMPTC authors and distributed for noncommercial use under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/). Source: [IMPTC dataset record](https://zenodo.org/records/14811016), Hetzel, Reichert, Reitberger, Doll and Sick. Preserve source attribution and license on reuse. Backgrounds are schematic geometry, not camera images.

inD raw files, trajectories, reconstructable maps, individual replay, checkpoints, private API routes and credentials are excluded. Only aggregate inD metrics are included. A public disabled inD selector explains this restriction. The original private server remains separate.

Public cases are licensed excerpts, not anonymization guarantees. IDs and time origins are reduced for data minimization; coordinates remain scientifically faithful. Do not apply the repository code license to dataset-derived material. The existing repository's old experiment files are preserved and outside this release's export.
